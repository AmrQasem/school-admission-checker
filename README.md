# متابعة فتح باب التقديم للمدارس (2027/2028)

سكريبت بايثون يفحص مواقع 3 مدارس بحثاً عن كلمات مثل "فتح باب التقديم"، "سجل الآن"،
"Apply Now"، وإذا وجدها يرسل لك إشعاراً فورياً على **إيميل** (بالنص الكامل والمكتوب
بالضبط في الموقع) و**مكالمة هاتفية آلية** (تنبيه سريع بالإنجليزي). يعمل تلقائياً
كل ساعة عبر GitHub Actions (مجاناً)، ويشتغل بكثافة أكبر (كل 15 دقيقة) حول يوم
1 أكتوبر 2026.

## الملفات

- `check_admissions.py` — السكريبت الأساسي.
- `requirements.txt` — المكتبات المطلوبة.
- `state.json` — يحفظ فيه السكريبت آخر نص تم الإشعار عنه لكل مدرسة، حتى لا يرسل
  نفس الإشعار مرات ومرات كل ساعة. يتحدث تلقائياً بعد كل تشغيل.
- `.github/workflows/check_admissions.yml` — إعداد GitHub Actions للتشغيل التلقائي.

   وده أكتر من كافي للتشغيل كل ساعة).
3. ارفع كل الملفات اللي في هذا المجلد (بنفس الهيكل، يعني مجلد `.github/workflows`

1 أكتوبر.

## هل ممكن ترسل نفس الإشعار كذا مرة؟

لأ. أول ما السكريبت يلاقي نص معين مطابق ("فتح باب التقديم" مثلاً) في موقع
مدرسة معينة، بيحفظه في `state.json` وميرسلوش تاني إلا لو النص اتغيّر أو
ظهرت عبارة جديدة. الملف ده بيتحدث تلقائياً على الـ Repository بعد كل تشغيل.

## تعديل قائمة المدارس أو الكلمات المفتاحية

كل ده موجود في أول ملف `check_admissions.py`:

- `SCHOOLS`: قائمة المدارس (الاسم + الرابط).
- `KEYWORDS`: الكلمات اللي بيدور عليها السكريبت.

تقدري تضيفي مدرسة رابعة أو كلمة جديدة بكل بساطة بإضافة سطر في القائمة المناسبة.
